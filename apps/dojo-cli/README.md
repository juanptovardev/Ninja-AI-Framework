# @ninja/dojo-cli

**Dojo CLI** es el cliente de terminal de Ninja AI Framework.

Es el punto de entrada principal cuando el usuario ejecuta `ninja` en su terminal.

## Responsabilidades

- Mostrar el banner y menú inicial de Ninja
- Permitir arrancar el sistema
- Mostrar estado del runtime
- Abrir el dashboard Forge Console en el navegador
- Actuar como superficie de control desde terminal

## Uso

```bash
pnpm cli:dev
```
