   flip real de readiness (503) queda probado en F2.1 con SQLite real. Compensación anotada para

   para no duplicar ruta; registrar sin wire habría dejado un módulo huérfano.

   bajo forks paralelos (10s default era intermitente). Afecta solo hooks, no testTimeout.

   (respaldo primario = repo GitHub privado).
